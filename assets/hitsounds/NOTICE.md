# Provenance notice — hyprbeat hitsound assets

All files in this directory (`normal.wav`, `clap.wav`, `whistle.wav`,
`finish.wav`) are **original synthesized content** created for hyprbeat by
the committed generator script `dev/gen_assets.py` (deterministic, seeded —
running it reproduces these files byte-for-byte). They contain no sampled
third-party material.

**License: CC0 1.0 Universal** (`https://creativecommons.org/publicdomain/zero/1.0/`).
The project's copyright posture requires bundled content to be CC-licensed or
original (CONTEXT.md §2, invariant I-03); this directory satisfies it by being
original. `git ls-files assets/` is the audit surface.

The sounds are intentionally minimal rhythm-game hitsound prototypes
(soft tick / clap / whistle / finish); skin support arrives in v0.2+
(CONTEXT.md §7.6).
